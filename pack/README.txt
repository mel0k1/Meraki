Meraki — Windows-оболочка на движке SwineWM (тайлинг + док в стиле macOS).

Состав архива
-------------
meraki.exe        — сама оболочка (движок окон + QML-интерфейс)
switcher.exe       — переключатель оболочки (две кнопки)
swinemenu.exe      — лаунчер приложений
notify-send.exe,
makoctl.exe        — уведомления (Mako-совместимые)
config, waybar/,
mako/, wallpapers/ — конфиг и ресурсы
widgets.example.json — пример настройки виджетов

Как попробовать Meraki
----------------------
1. Распакуйте архив целиком в любую папку (например C:\Meraki).
2. Запустите switcher.exe.
3. Нажмите «Поставить Meraki» — Explorer закроется, запустится Meraki,
   и он пропишется оболочкой для вашего пользователя
   (HKCU\...\Winlogon\Shell, права администратора не нужны).
4. Чтобы вернуться на Explorer — запустите switcher.exe снова
   (например, из swinemenu.exe или из проводника папки) и нажмите
   «Вернуть Explorer». Meraki закроется, вернётся привычный рабочий стол.

Важно
-----
- Если после «Поставить Meraki» экран пуст: нажмите Win+D — откроется
  Launchpad (лаунчер Meraki), из него можно запустить switcher.exe или
  любую программу. Win+Shift+E закрывает Meraki и возвращает все окна.
- Держите switcher.exe под рукой: он возвращает Explorer в один клик.
- Смена оболочки действует для текущего пользователя и переживает
  перезагрузку. Отменить можно в любой момент кнопкой «Вернуть Explorer»
  (движок при этом сам чистит реестр — meraki --unset-shell).
- Управление Meraki (по умолчанию): Win+D — Launchpad, Win+Shift+Q —
  закрыть окно, Win+1..0 — рабочие столы, Win+стрелки — фокус,
  Win+Shift+E — выход. Полный список — файл config в архиве.
- Виджеты (часы, календарь, погода, медиа) можно перетаскивать мышью —
  позиции запоминаются в %USERPROFILE%\.swinewm\widgets.json (секция
  "positions"). Сам файл применяется на лету: правьте — виджеты перестроятся.
- Hotplug мониторов: бар, док и виджеты появляются/исчезают вместе с
  экранами без перезапуска (трей — на основном).
- Поверх Meraki работает лаунчер swinemenu.exe (меню приложений) и
  notify-send.exe для уведомлений из скриптов.
- Мультидисплей: бар, док и виджеты появляются на каждом мониторе
  (трей — только на основном).
- Виджеты настраиваются файлом %USERPROFILE%\.swinewm\widgets.json:
  скопируйте widgets.example.json из архива и правьте (какие карточки
  показывать, размеры, сторона экрана, отступы, единицы погоды,
  секция "positions" — сохранённые позиции перетаскиванием).
  Изменения подхватываются на лету, без перезапуска.
